#  Netflix Content Analytics | ELT Project

##  Project Overview

This project demonstrates an end-to-end ELT (Extract, Load, Transform) pipeline using the Netflix Movies & TV Shows dataset. Data is extracted using Python (Pandas), loaded into python, and transformed with SQL to answer key business questions and generate actionable insights.

Business Objectives

- Identify directors who have created both Movies and TV Shows.
- Find the country with the highest number of Comedy Movies.
- Determine the top movie director for each year.
- Analyze the average duration of movies by genre.
- Identify directors who have directed both Comedy and Horror movies.

## Tech Stack

- **MySQL** – Data Loading
